# 🧒 Baby Flashcards

**Baby Flashcards**는 숫자, 알파벳, 단어를 재미있고 직관적으로 학습할 수 있도록 설계된 유아용 플래시카드 웹앱입니다.  
👶 *저희 아이를 위해 직접 만든 프로젝트지만, 모든 아이들에게 도움이 되길 바랍니다!*

**Baby Flashcards** is a flashcard web app designed to help young children learn numbers, alphabets, and words in a fun and intuitive way.  
👶 *Originally created for my own child, I hope this project can help kids everywhere enjoy learning too!*

> ⚠️ **Note:** The website is currently offline for maintenance or updates.

## 📦 Features

- 직관적이고 반응형 UI
- 이미지 기반 플래시카드
- 자동/수동 전환 기능
- TTS(Text-to-Speech) 발음 지원
- 퀴즈 및 학습 통계 제공 예정

---

## 🚀 Tech Stack

- **React** + **Vite**
- **Tailwind CSS**
- **React Router**
- **Lucide Icons**
